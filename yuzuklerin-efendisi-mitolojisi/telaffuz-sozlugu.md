# Telaffuz Sözlüğü

Tolkien'in isimleri kendi uydurduğu Elf dillerindendir (Quenya ve Sindarin). Türkçeye çok yakın okunurlar; birkaç kuralı bilmek yeterli. Büyük harfle yazılan hece vurguludur.

## Temel kurallar

| Harf | Nasıl okunur | Örnek |
|---|---|---|
| **c** | her zaman **k** | Cuiviénen → *kuy-vi-E-nen* |
| **qu** | **kv** (İngilizce "kw"ye yakın) | Quendi → *KVEN-di* |
| **th** | peltek **s** (İngilizce *think*) | Thingol → *THİN-gol* |
| **dh** | peltek **z** (İngilizce *this*) | Maedhros → *MAY-dhros* |
| **w** | hafif **v** / İngilizce **w** | Manwë → *MAN-ve* |
| **y** (ünsüz) | Türkçe **y** | Vanyar → *VAN-yar* |
| **ai** | **ay** | Ainur → *AY-nur* |
| **au** | **av** (İngilizce *loud*) | Aulë → *AV-le* |
| **ui** | **uy** | Cuiviénen → *kuy-vi-E-nen* |
| **ë** (sonda) | okunan bir **e**; sessiz değildir | Eönwë → *E-on-ve* |
| **é, á, ú, ó, í** | uzun ünlü, vurguyu çeker | Ilúvatar → *i-LU-va-tar* |
| **çift ünsüz** | uzatılarak okunur | Illuin → *İL-lu-in* |

**Vurgu kuralı (Quenya):** İki heceli kelimelerde ilk hece; daha uzun kelimelerde sondan ikinci hece "uzunsa" (uzun ünlü veya ardında iki ünsüz varsa) oraya, değilse sondan üçüncü heceye.
